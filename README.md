# apilivehq/homebrew-tap

Homebrew tap for [api.live](https://api.live), the local-first API workbench (free to use, proprietary).

```bash
brew install --cask apilivehq/tap/api-live      # desktop app (macOS)
brew install apilivehq/tap/api-live-cli         # `api` CLI + MCP server (macOS, Linux)
```

The formulae download the official builds from https://github.com/apilivehq/apilive/releases and check their
SHA-256. Issues: https://github.com/apilivehq/apilive/issues
